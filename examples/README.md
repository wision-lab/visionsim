Example blender files can be downloaded [from here](https://drive.google.com/drive/folders/1gRxhL3rbGDTfgKytre8WkbBu-QDJFy15?usp=sharing). To run the examples, please download and unzip the example blender files from the `assets` folder. Using the gdown package (eg: `pip install gdown` or `uv tool install gdown`) you can simply run the following *inside this examples directory*:

```
gdown --fuzzy --folder https://drive.google.com/drive/folders/16HvbXAYI2vELb9RlBtSvKA9uqhWSAdJg?usp=sharing
```

You should now have and `assets` directory in `visionsim/examples`. From here, you can run examples like so:
```
python blender/render_animation.py 
```
